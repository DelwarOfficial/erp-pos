# বাংলা–ইংরেজি শব্দকোষ

[সূচিপত্র](README.md)

| শব্দ | সহজ অর্থ |
|---|---|
| ERP | বিক্রয়, পণ্য, টাকা ও কাজের রেকর্ড এক জায়গায় রাখার ব্যবস্থা। |
| POS | দোকানের কাউন্টারে বিক্রয় লেখার পর্দা। |
| Company / কোম্পানি | যার ব্যবসা ও হিসাব আলাদা রাখা হয়। |
| Branch / শাখা | একই কোম্পানির একটি দোকান বা কার্যস্থল। |
| Warehouse / গুদাম | যে স্থান বা স্টক অবস্থান থেকে পণ্য আসে বা যায়। |
| Customer / কাস্টমার | দোকান থেকে পণ্য কেনেন যিনি। |
| Supplier / সাপ্লায়ার | দোকানকে পণ্য দেন যিনি। |
| Stock / স্টক | পণ্যের মজুত। বিক্রয়যোগ্য, সংরক্ষিত, পথে থাকা ও ক্ষতিগ্রস্ত মজুত আলাদা হতে পারে। |
| SKU / Product code | পণ্যের ধরন চেনার নিজস্ব কোড। একটি নির্দিষ্ট ডিভাইসের সিরিয়াল নয়। |
| Barcode / বারকোড | স্ক্যান করে পণ্য খোঁজার চিহ্ন। |
| Serial / IMEI / সিরিয়াল | একটি নির্দিষ্ট ডিভাইস চেনার নম্বর। বাক্স ও ডিভাইস মিলিয়ে নিতে হয়। |
| Unit / একক | পরিমাণের মাপ; যেমন একটি পিস। |
| Batch / ব্যাচ | একসঙ্গে পাওয়া পণ্যের দল; মেয়াদও থাকতে পারে। |
| Opening stock / শুরুর স্টক | সিস্টেমে কাজ শুরুর সময়ের মজুত ও মূল্য। নিয়মিত গ্রহণ নয়। |
| Purchase order / ক্রয়াদেশ | সাপ্লায়ারের কাছে কত পণ্য চাওয়া হয়েছে তার রেকর্ড। |
| Receiving / পণ্য গ্রহণ | বাস্তবে আসা পণ্য গ্রহণ করে স্টক বাড়ানোর কাজ। |
| Transfer / ট্রান্সফার | এক গুদাম থেকে অন্য গুদামে পণ্য পাঠানো। |
| Adjustment / স্টক সমন্বয় | কারণ লিখে মজুতে অনুমোদিত সংশোধন। |
| Stock count / স্টক গণনা | বাস্তব গুনতি ও সিস্টেমের পরিমাণ তুলনা। |
| Shift / শিফট | নির্দিষ্ট ক্যাশিয়ারের কাজ ও ক্যাশ ড্রয়ারের সময়ভিত্তিক রেকর্ড। |
| Payment account / পেমেন্ট অ্যাকাউন্ট | যে ক্যাশ, ব্যাংক বা ওয়ালেটে টাকা আসে বা যায়। লগইন অ্যাকাউন্ট নয়। |
| Credit sale / বাকিতে বিক্রি | পণ্য এখন দেওয়া, টাকার কিছু বা সব পরে নেওয়া। |
| Installment / কিস্তি | নির্ধারিত তারিখে বকেয়ার একটি অংশ। |
| Collection / আদায় | আগের বাকির টাকা পাওয়া ও রেকর্ড করা। নতুন বিক্রয় নয়। |
| Return / বিক্রয় ফেরত | বিক্রি করা পণ্য ফেরত নেওয়া ও তার ক্রেডিট হিসাব করা। |
| Refund / টাকা ফেরত | কাস্টমারকে অর্থ ফেরত দেওয়া। Return থেকে আলাদা কাজ। |
| Post / চূড়ান্ত নথিভুক্ত করা | স্টক বা হিসাবে কার্যকর রেকর্ড তৈরি করা। শুধু খসড়া রাখা নয়। |
| Journal / হিসাবের এন্ট্রি | কোন খাতে কত ডেবিট ও ক্রেডিট হলো তার নথি। |
| Debit / Credit | হিসাবের দুই দিক। সরাসরি লাভ/ক্ষতি বা টাকা আসা/যাওয়ার সমার্থক নয়। |
| Fiscal period / হিসাবকাল | যে সময়ের তারিখে হিসাব নথিভুক্ত করা যায়। বন্ধ বা locked হলে বাধা আসতে পারে। |
| Role / ভূমিকা | কয়েকটি কাজের অনুমতি একসঙ্গে দেওয়ার ব্যবস্থা। |
| Permission / অনুমতি | নির্দিষ্ট কাজ দেখার বা করার অধিকার। |
| Feature flag / ঐচ্ছিক ফিচারের সুইচ | কোম্পানিতে নির্দিষ্ট মডিউল চালু কি না তার নিয়ন্ত্রণ। অনুমতির বিকল্প নয়। |
| MFA / দুই ধাপের যাচাই | পাসওয়ার্ডের পর অতিরিক্ত পরিচয় যাচাই। |
| Passkey / পাসকি | নিজের ডিভাইস বা নিরাপত্তা কী দিয়ে পরিচয় যাচাইয়ের উপায়। |
| Reference / রেফারেন্স | নথি খুঁজে পাওয়ার পরিচিতি নম্বর। |
| Allocation / পেমেন্ট বণ্টন | পাওয়া টাকার কোন অংশ কোন invoice বা কিস্তির বকেয়ায় বসেছে। |
| Registry / বাস্তবায়িত মডিউলের তালিকা | সফটওয়্যারে কোন মডিউল enable করা যাবে তার নিয়ন্ত্রণ তালিকা। |
| Tender / পরিশোধের মাধ্যম | Cash, card বা অন্য যে মাধ্যমে বিক্রয়ের টাকা দেওয়া হয়। |
| Detail truncation / বিস্তারিত তালিকার সীমা | অনেক রেকর্ড হলে সব row না দেখিয়ে নির্দিষ্ট সংখ্যায় থামানো। Summary-এর মোটের সঙ্গে পার্থক্য হতে পারে। |
| Audit log / কার্যকলাপের ইতিহাস | কে কখন কী পরিবর্তন করেছেন তার রেকর্ড। |
| COD | ডেলিভারির সময় কাস্টমারের কাছ থেকে টাকা নেওয়া। |

এই গাইডে একই অর্থে “স্টক”, “কাস্টমার”, “সাপ্লায়ার”, “আদায়” ও “টাকা ফেরত” ব্যবহার করা হয়েছে।
