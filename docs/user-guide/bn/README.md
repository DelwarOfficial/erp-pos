# ERP/POS ব্যবহারিক গাইড

বাংলাদেশের ইলেকট্রনিকস দোকানের নতুন কর্মীদের জন্য। এটি এই প্রকল্পের গাইড; ERPNext-এর গাইড নয়।

**পর্যালোচনার তারিখ:** ১৭ নভেম্বর ২০২৬। **সোর্স সংস্করণ:** `b55feec` ও তখনকার working tree। পরে পরিবর্তন হলে বোতাম ও নিয়ম পুনরায় মিলিয়ে নিন।

**প্রথমে পড়ুন:** [শুরু করুন](START.md), [শব্দকোষ](GLOSSARY.md), [যাচাই ও সীমাবদ্ধতা](VERIFICATION.md)।

## প্রমাণের সীমা

ব্যবহারকারীর অনুমোদিত লোকাল ডেমোয় লগইন সফল হয়েছে। Global administrator session-এ ৪৮টি dashboard পৃষ্ঠা ও ১৮টি নতুন-রেকর্ড/সম্পাদনার form শুধু খুলে দেখা হয়েছে। Login/reset-এর খালি form-ও দেখা হয়েছে। বিস্তারিত নথির কার্যপ্রবাহ ও posting-এর নির্দেশনা সোর্সের সঙ্গে মিলিয়ে লেখা; কোনো বিক্রয়, stock পরিবর্তন, payment, refund বা SMS সম্পন্ন করা হয়নি। Import Jobs-এ HTTP 500 এবং System Health-এ Redis failure পাওয়া গেছে।

ইংরেজি interface-এর বোতাম হুবহু দেওয়া হয়েছে। বাংলা ভাষা বেছে নিলে কিছু নাম অনূদিত হবে; অন্য পৃষ্ঠায় ইংরেজি থাকতে পারে। উদাহরণের সব নাম, টাকা ও পরিমাণ কাল্পনিক।
